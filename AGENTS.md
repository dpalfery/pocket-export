# Pocket Export (`pocket-export`) — Agent Policy & Config Registry

## Project Overview

`pocket-export` is a cross-platform (Windows 11 primary with NVIDIA RTX 5090 24GB + 64GB RAM running on AC power; macOS Apple Silicon secondary) desktop application and background sync/transcription/classification pipeline for Pocket AI voice recordings (`heypocketai.com`).

### Core Architecture Decisions
- **Desktop GUI:** Tauri v2 + React + TypeScript frontend (`src-ui` / `src-tauri`).
- **Core Backend & Orchestrator:** C# (.NET 9/10) ASP.NET Core Web API + `BackgroundService` (`src/PocketExport.Api` / `src/PocketExport.Core`).
- **Audio ML Sidecar:** Hermetic Python 3.12 worker (`uv`, `src/audio-worker`) running local ASR (`nvidia/parakeet-tdt-0.6b-v2` / `whisper-large-v3-turbo` via `faster-whisper` on CUDA 12.8 / `mlx-whisper` on macOS), forced alignment (`WhisperX` Wav2Vec2), speaker diarization (`pyannote/speaker-diarization-community-1`), and 512-d speaker biometric voiceprint extraction (`WeSpeaker CAM++`).
- **Decision & Summarization Runtime:** Local LLM via LM Studio (`http://localhost:1234/v1`) and/or local zero-shot classifier (`GLiNER`) using taxonomy rules and prescribed Markdown summary templates.
- **Storage & Multi-Machine Sync:** All files—including `staging/` raw audio, Pocket cloud metadata JSON, `.ledger/` state/voicebank/taxonomy manifests, and `routed/` transcripts & summaries—live inside a shared **OneDrive VaultRoot** using relative POSIX paths. Each machine maintains a fast local SQLite index hydrated from `VaultRoot/.ledger/` to prevent OneDrive binary SQLite corruption.
